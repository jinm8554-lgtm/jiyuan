# 裂隙纪元 · Aetherfall Chronicle

> 一款全年龄向的架空中世纪西幻 RPG：领地经营 × 角色收集 × 队伍养成 × 世界探索 × 区域征服 × 回合制战斗 × AI 角色互动。

七年前的「星陨之夜」，天空裂开一道长缝。裂缝中涌出两样东西：**星辉（Aether）** 与 **蚀影（Blightborn）**。
星辉让凡人第一次摸到魔法的温度，蚀影则把一切未曾安葬的记忆重新拖回地面。
旧王国在盐铁战争、灰喉疫病与魔物灾害中崩坏，贵族各自固守。
你继承了瓦尔登家族最后的封地——银杉边境上的灰隼堡。
家族留下的不是财富，而是一张写满债务与承诺的账本，以及一面被反复缝补的灰隼旗。

| 项 | 说明 |
| --- | --- |
| 类型 | 中世纪西幻 RPG（领地经营 + 抽卡收集 + 回合制战斗 + AI 角色互动） |

## 核心循环

```
经营（建领地） → 集结（招募/养成） → 探索（世界地图） → 征服（战斗/占领） → 反哺领地
```

游戏包含 **6 大区域、35 个可攻克节点、7 种职业分工、15 名原创角色、6 个剧情章节**。

## 快速开始

```bash
pnpm install
node scripts/migrate.mjs        # 建表（幂等）
pnpm tsx scripts/seed.ts        # 写入内置策划配置
pnpm dev                        # 启动开发服务器（默认 3000 端口）
```

成为管理员（GM 后台需要 `role='admin'`）：

```bash
pnpm tsx scripts/seed.ts --admin <openId 或 userId>
```

质量门禁：

```bash
pnpm check    # TypeScript 类型检查，0 错误
pnpm test     # 68 个测试全部通过
```

## 架构要点

**服务端权威**：概率、保底计数、战斗结算、奖励、解锁判定全部在服务端计算，客户端仅做展示。

**纯逻辑分层**：`server/game/` 下的数值、战斗、抽卡、AI 校验均为可独立测试的纯逻辑；
`server/routers/` 只负责「鉴权 → 校验入参 → 调服务层 → 返回 DTO」。

**AI 硬性约束**：

- 只把玩家当前选中的「在场角色」传入提示词，未选中的角色不得发言或行动。
- 输出必须是结构化 JSON，经 JSON Schema + 业务双层校验；未知角色 ID 的发言被拒绝。
- AI 不得改写角色身份、设定、阵营或性格（这些字段只从角色库读取）。
- 没有在场角色时，界面提示玩家先选择，**且不发起任何模型调用**。
- 模型配置由 GM 后台统一控制，客户端无法覆盖。

**安全**：AI 的 API Key 以 AES-256-GCM 加密入库且只显示遮罩；会员 Token 只存 SHA-256 哈希与前缀，
明文仅在签发时返回一次；密钥、密码、Token 均不出现在前端代码或公开仓库中。

## 项目结构

```
aetherfall/
├─ client/          前端（页面 / 组件 / 设计令牌）
├─ server/          后端（路由 + 纯逻辑层 + 配置数据）
│  ├─ routers/      tRPC 过程（meta/keep/character/recruit/world/battle/ai/admin）
│  └─ game/         数值、战斗、抽卡、AI、备份、服务层与策划数据
├─ drizzle/         33 张表的 Schema 与迁移 SQL
├─ scripts/         迁移执行器、配置写入 CLI、资源优化
├─ docs/            设计、架构、AI、开发、部署、备份、测试、扩展文档
```

基础人物头像、立绘以及主城、地图、议事、战斗场景资源已随源码放在
`client/public/aetherfall-assets/`，新部署不需要访问原沙盒的对象存储即可显示基础游戏画面。

## 全年龄向声明

《裂隙纪元》为全年龄向作品。本项目不含色情内容、性奴役、色情服装或身体羞辱。
全部角色以冒险者、骑士、法师、领主、学者、工匠、商旅等正向身份登场，
亲密表达限于友情、同伴信任、家族羁绊、骑士精神与轻度恋爱。
