# 《裂隙纪元》视觉设计提案（Visual Design Proposal）

> 本提案为原创设计体系，不模仿任何具体游戏的界面结构、配色方案或美术素材；所有插画、立绘与图标均由本项目自行生成（AI 原创）+ CSS/SVG 自绘，不含任何受版权保护的素材。
> 设计目标：**一眼可辨的「边境余晖」气质 —— 冷蓝的星辉与暖金的炉火互相拉扯，羊皮纸的旧文明压在锻铁的新秩序之上。**

---

## 1. 视觉关键词

`边境余晖` `羊皮纸与锻铁` `纹章学` `星辉裂隙` `手抄本` `褪色的金色` `石与雾`

一句话方向：**在破败的石墙之间，保存一盏还未熄灭的灯。**

---

## 2. 世界观氛围（视觉转译）

| 叙事元素 | 视觉语言 |
|---|---|
| 崩坏的旧王国 | 褪色、磨损、裂纹、边角缺损的边框；低饱和的灰绿与土黄 |
| 星辉（魔法） | 冷青蓝发光：细线光晕、扫描式流动、发光符文 |
| 炉火与文明（领地） | 暖橙金：火光渐变、锻铁高光、羊皮纸暖底 |
| 蚀影（敌人） | 无实体的暗紫灰雾、被撕开的边缘、低对比、缓慢漂移 |
| 边境与远征 | 地图、旗帜、蜡封、纹章、罗盘 |

整体明暗基调：**深色底（深夜石板）+ 暖金强调 + 冷青点缀**，让长时间阅读不疲劳，并突出金色稀有物。

## 5. 主城界面方向（灰隼堡）

**结构：全屏城堡实景作为底层 + 三层信息浮层**

```
┌──────────────────────────────────────────────────────────────┐
│ [资源条] 金币 粮食 木料 铁矿 星辉 声望    [领主头像/等级/势力]│ ← 顶部：八边资源胶囊
├───────┬──────────────────────────────────────────┬───────────┤
│       │                                          │  议事厅   │
│ 塔楼  │       城堡实景（AI 原创插画/渐变天空）    │  待办卡   │
│ 旗帜  │   ●酒馆  ●兵营  ●工坊  ●图书馆           │ ─────────  │
│ 导航  │   ●议事厅 ●市场  ●城墙                   │  当前目标  │
│       │      建筑热点 = 发光光环 + 锻铁铭牌(Lv)   │ ─────────  │
│       │                                          │  领地状态  │
├───────┴──────────────────────────────────────────┴───────────┤
│ [队伍 4 格] [远征入口] [招募入口] [AI 篝火夜谈]                │ ← 底部行动坞
└──────────────────────────────────────────────────────────────┘
```

- **顶部资源条**：每个资源为「八边形切角胶囊」，左侧图标（自绘 SVG 线性图标），数值用 mono 字体；数值变化时数字滚动并闪金光。
- **左侧导航**：垂直「旗帜式」导航，选中项旗帜变为金色并向左延伸 12px，附带细星辉流光。
- **建筑热点**：圆形光环 + 呼吸动画；悬停时展开「锻铁铭牌」显示建筑名、等级、产出与升级按钮；未解锁建筑呈灰雾半透明。
- **议事厅待办卡**：列出 3 条最重要的事（可升级建筑、可领取任务奖励、新解锁区域），点击直达，保证「进入游戏即知目标」。
- **朝向新手的引导**：首次进入时，议事厅卡片显示「第一步：修复城墙」，并以金色描边脉冲提示。

## 6. 世界地图方向

- **底图**：羊皮纸质感的手绘古地图（AI 原创插画），带做旧边缘与烫金外框，四角有罗盘与纹章装饰。
- **区域节点**：以「蜡封圆章」表示，章内是区域纹章剪影；已占领 = 金色蜡封 + 外圈金环；可探索 = 银灰蜡封；锁定 = 灰雾蜡封 + 铁锁图标。
- **区域间连接线**：手绘虚线，已打通的路段变为实线并带流动光点（表示商路）。
- **交互**：悬停显示区域卡片（危险度、敌人判定、奖励预览、解锁条件）；点击进入区域详情面板（节点列表 + 征服进度条 + 剧情入口）。
- **移动端**：地图可拖拽缩放，底部以抽屉形式展示「区域列表」，区域卡片竖排。

## 7. 角色卡与角色详情方向

### 7.1 角色卡（竖版 2:3）
```
┌────────────┐
│  ▲ 角标(职业) │  ← 左上：职业剪影徽记
│            │
│   立绘      │  ← 半身立绘，底部渐变融黑
│            │
│ ▓▓▓▓▓▓▓ │  ← 稀有度材质边框（铜/银/金）
│ 姓名        │  ← 铭牌区（暗金底 + 阴刻文字）
│ 称号 · Lv   │
│ [职业][种族] │
└────────────┘
```
- 悬停：上浮 4px，金色描边加亮，立绘轻微 scale(1.03)，稀有度光晕增强。
- 已拥有 → 显示等级条与羁绊心标；未拥有 → 显示「未获得」灰雾遮罩。
- 上阵中 → 右下角「队伍徽记」角标。

### 7.2 角色详情页
- 左栏（40%）：立绘大图 + 稀有度光环 + 语音台词的「手抄本纸条」+ 上阵/编队按钮。
- 右栏：Tab 分栏 —— **属性 / 技能 / 装备 / 羁绊 / 语音 / 剧情**
  - 属性：数值 + 成长曲线折线图（自绘 SVG）+ 装备加成对比（绿色 +N）。
  - 技能：技能卡（类型/元素/倍率/冷却），升级按钮与升级消耗。
  - 装备：6 个装备槽（武器/副手/头盔/护甲/靴子/饰品），空槽为锻铁虚线框，点击打开装备选择抽屉（显示属性差量）。
  - 羁绊：羁绊等级进度 + 与该角色相关的角色头像连线图。
  - 语音：台词列表（播放按钮为装饰，或调用 TTS 时可用）。
  - 剧情：该角色的剧情状态与解锁节点。

## 8. 战斗界面方向

- **视角**：斜 45° 伪透视战场，敌方在左上，我方在右下；地面为半透明石纹平台。
- **站位条**：前排 / 后排两条带状区域，位置影响被选为目标概率与部分技能效果。
- **单位表现**：立绘头像 + 铁质血条（内发光）+ 状态图标行（最多 5 个，溢出显示 +N）。
- **行动顺序条**：屏幕顶部横向排列（速度倒序），当前行动者放大并带金色时间指针。
- **我方指令**：底部圆形技能盘，技能按钮为「切角圆盘」；元素色描边；冷却以扇形遮罩表示；能量（星辉）不足时按钮变灰并提示需要回合数。
- **命中反馈**：伤害数字自下而上飘出并带元素色描边（暴击放大 1.3 倍 + 金色）；受击单位抖动 120ms、护盾破裂呈冰蓝碎片；治疗为 verdant 升腾光点。
- **胜负结算**：结算面板依次呈现 星级评价 → 经验/金币/装备掉落（逐条 stagger 入场）→ 角色升级提示。
- **移动端**：改为「列表式行动条 + 我方卡片横向滑动」；技能盘放大为 56px 触摸目标，目标选择用点击代替拖拽。

## 9. 图标、按钮、卡片规范

### 9.1 图标
- 线性图标：1.75px 描边、圆角端点、24×24 网格；尺寸档 24 / 20 / 16。
- 类别图标（职业、元素、资源）使用**剪影填充**样式，保证小尺寸可辨识。
- 所有图标为自绘 SVG（内联组件），不引用外部图标库以外的版权素材（lucide 为 MIT，可用于功能类图标）。
- 未加载/缺失图标 → 显示自有纹章占位符。

### 9.2 按钮
| 类型 | 视觉 | 尺寸 |
|---|---|---|
| 主按钮（主要行动） | 赤金渐变 `--gold-600 → --gold-500`，右上 8px 斜切角，内描边 1px `--gold-300`，文字 `--ink-950` 700 | h 40/36/32 |
| 次按钮 | 透明底 + `--gold-500` 1px 边框，文字 `--gold-300` | 同上 |
| 幽灵按钮 | 无边框，hover 时出现 `--ink-600` 底 | 同上 |
| 危险按钮 | `--ember-600 → --ember-400` 渐变，文字 `--ink-950` | 同上 |
| 禁用 | 降饱和 + 40% 透明度 + `cursor: not-allowed` | — |

- 圆角统一 6px，切角 8px；按下 `scale(0.97)`，过渡 160ms `--ease-out`。
- 主按钮带轻微「锻打高光」：`linear-gradient` 顶部 40% 更亮。

### 9.3 卡片
- 底 `--ink-700`；1px 边框 `rgba(201,162,39,0.22)`；**双层描边**：外层 `--ink-950` 1px，内层金色 1px 内阴影。
- 阴影 `0 8px 24px rgba(0,0,0,0.45)`；悬停升为 `0 14px 34px rgba(0,0,0,0.55)` + 金色描边加强。
- 面板标题左侧有「金色竖条」装饰（4×18px）。
- 需要「羊皮纸」语义的区块（剧情、信件、告示）使用暖底羊皮纸变体：底 `#1E1A14`，文字 `--parchment`，边框 `--gold-600` 40%。

### 9.4 纹理与背景
- 全局背景：`--ink-900` + 细噪点（SVG feTurbulence 转 base64）+ 顶部星辉径向渐变。
- 面板叠一层 2% 不透明度的斜向纹理，避免纯色平板感。
- 不使用外部图片纹理，全部程序化生成，保证加载性能。

## 10. 动效原则

1. **时长**：UI 反馈 100–160ms；下拉/弹层 150–250ms；模态/抽屉 200–500ms；战斗动画 300–700ms。全部 ≤800ms。
2. **缓动**：进入 `--ease-out: cubic-bezier(0.23,1,0.32,1)`；位移/形变 `--ease-in-out: cubic-bezier(0.77,0,0.175,1)`；禁止使用 `ease-in`。
3. **绝不从 `scale(0)` 出现**，最低 `scale(0.95) + opacity:0`。列表入场 stagger 40ms。
4. **只动画 `transform` 与 `opacity`**，避免 layout 抖动。
5. **资源数值变化**：数字滚动 500ms + 金光闪烁一次；不足时抖动并变红 600ms。
6. **战斗**：伤害飘字 700ms 上飘淡出；受击抖动 120ms；护盾破裂 260ms；濒死单位血条呼吸（2s 循环）。
7. **稀有度光晕**：SSR 呼吸周期 3.2s（无动画偏好时静止）。
8. **页面切换**：主内容区 4px 上移 + 淡入 220ms；战斗进入使用「星辉裂隙张开」遮罩 400ms。
9. **可访问性**：`prefers-reduced-motion: reduce` 时关闭呼吸/流光/抖动，仅保留 ≤120ms 的透明度过渡。

## 11. 桌面端与移动端适配策略

| 断点 | 设备 | 布局策略 |
|---|---|---|
| `< 768px` | 手机 | 底部 Tab（主城/角色/远征/招募/议会）；次级导航抽屉化；角色卡 2 列；地图可拖拽 + 底部区域抽屉；战斗为列表式行动条 + 56px 技能盘；表格改为卡片列表 |
| `768–1279px` | 平板 / 小笔电 | 左侧导航折叠为 56px 图标条；角色卡 3 列；战斗保留战场但左右收窄；主城三栏合并为两栏 |
| `≥ 1280px` | 桌面 | 三栏（导航 240px + 主内容 + 上下文栏 320px）；角色卡 4–5 列；战斗完整战场 |

- 字体与间距使用 `clamp()` 流式缩放（如 `font-size: clamp(14px, 0.9vw + 11px, 16px)`）。
- 触摸目标：移动端≥44px，战斗技能按钮≥56px，资源条图标间距≥8px。
- 图片：固定 `aspect-ratio` 占位防抖动；`loading="lazy"`；加载失败显示纹章占位 SVG（自绘），并保留文字信息。
- 横屏战斗：`orientation: landscape` 时压缩顶部顺序条为悬浮胶囊。
- 桌面端优势功能：键盘快捷键（1–4 选择角色，Q/W/E/R 技能，Space 普攻，Esc 取消）、悬停信息浮层、并排对比装备。
