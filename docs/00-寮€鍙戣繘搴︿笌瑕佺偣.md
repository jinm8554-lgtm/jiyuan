## 重要约定与踩过的坑
- 客户端不得计算概率/保底/战斗结果/奖励，全部服务端权威
- AI 只接收玩家选中的在场角色；输出 JSON Schema 校验；未知角色发言被拒；无在场角色时不调用模型
- 全年龄向：禁止色情/性奴役/色情服装/身体羞辱；可含友情、羁绊、骑士精神与轻度恋爱
- **`tRPC createCaller` 返回根 caller**：测试中须写 `caller.admin.xxx()`，不是 `caller.admin` 当作对象
- **`serializeState` 必须保留 `cursor` / `rngSeed` / `log` / `nodeKey` / `regionKey` / `keepBonusReduction`**，否则恢复战斗会卡死或抛 `log.push` 未定义
- **`seed.ts` force 模式必须逐行 upsert**，否则所有行会被写成第一行的值（曾导致 15 个角色全变成同一个人）
- `listPlayerProfiles` 不返回 wood/iron；需用 `keep.home().resources` 取全量资源
- `Roster.tsx` 的 `useEffect` 依赖稳定签名字符串，不能依赖 `activeTeam` 对象引用（否则冲掉未保存编辑）
- 首次交付前不要创建 checkpoint（交付时创建一次）
